### 서브에이전트 위임

- 메인 모델·추론 수준은 사용자가 선택한다. 아래 기준은 서브에이전트에만 적용하며, 사용자 지정 모델·위임 제한·예산·승인과 프로젝트 제한이 우선한다. 이 정책은 외부 판단 엔진·API·훅·분류기·상태 저장 없이 매 요청마다 하는 일회성 내부 자연어 판단이며, 판단·계획·작업 기록을 `AGENTS.md`에 누적하지 않는다.
- 요청 전체는 `readiness=ready|partial|blocked`, 각 작업은 `status=ready|blocked`로만 정리한다. `ready|partial`은 실행 가능한 일이 있을 때 `planned_execution=direct|mixed`, `blocked`는 `none`을 쓰며, `mixed`에는 준비된 위임과 독립적인 메인 병행 작업이 모두 있어야 한다. 이 값은 호출 성공·실행·결과의 증거가 아니며, 현재 환경에는 순수 위임(`pure delegate`)이 없다. 메인이 언제나 통합·최종 검증·보고 책임을 진다.
- `blocked`는 막힌 범위, 자연어 이유, `needed_to_unblock`을 함께 적고 사용자 입력/승인·정책 금지·근거 부족·도구 접근·미지원 중 원인을 구분한다. 현재 권한과 도구로 범위 안에서 바로 해소할 선행 확인은 차단이 아니라 `ready` 작업의 실행 순서다. `partial`은 막힌 작업과 결과·의존성이 독립이고 사용자의 선택지를 좁히지 않는 되돌릴 수 있는 안전한 로컬 작업만 계속할 때 쓴다.
- 사용자는 적극 위임을 선호한다. 메인은 분리 가능한 조사·구현·검토와 병행할 유용한 일을 먼저 찾되, 짧은 단일 작업·전달 비용이 더 큰 일·병행 이득이 없는 일은 직접 한다. 작업명·대화 길이·파일 수가 아니라 모호성·오류 영향·검증 난도로 판단한다.

| 위임 작업의 성격 | 모델 | 추론 수준 |
| --- | --- | --- |
| 기준이 명확한 추출·분류·파일 위치 탐색 | `gpt-5.6-luna` | `low` |
| 질문과 출처 범위가 좁은 웹 조사·공식 문서 사실 확인 | `gpt-5.6-luna` | `medium` |
| 여러 출처 비교·코드 경로 추적·독립적인 일반 구현과 테스트 | `gpt-5.6-terra` | `medium` |
| 상충하는 근거 해석·복잡한 원인 분석·보안 및 중요한 변경 검토 | `gpt-5.6-sol` | `high` |
| 여러 영역에 걸친 모호한 설계로 별도의 깊은 판단이 꼭 필요한 작업 | `gpt-6-astra` | `high` |

- 실제 지원 조합·도구 접근을 확인하고 모델과 추론 수준을 호출 인수로 함께 지정한다. 고정 모델인 사용자 정의 역할이 선택과 충돌하면 쓰지 않는다. 미지원이면 허용 조합으로 바꾸거나 메인이 직접 맡고, 모델 상속·계획을 성공으로 보거나 예산·설정·권한을 우회하지 않는다.
- 위임에는 목표·완료 기준·루트·읽기/수정/제외 범위·적용 `AGENTS.md`/스킬 경로·확인/미확인 사실·대화 전용 제약(승인·허용 모델·예산·동시 인원·네트워크·푸시)·도구·모델/추론·반환할 근거/변경/검증을 정확히 전달하고 무관한 정보는 제외한다. 담당·모델·추론·이유를 사용자에게 짧게 알리고, 담당 범위를 겹치지 않게 하며 동시 한도가 차면 완료 후 배정한다. 재위임을 따로 허용하지 않으면 서브에이전트가 직접 수행하게 하고 결과의 근거·변경·검증·미확인을 검토한다.
- 권한·정책·확정된 미지원은 재시도 0회, 일시 도구 오류는 1회, 근거 누락 보완은 1회만 한다. 추론 부족이면 미해결 범위만 1회 다시 판단해 재배정하며, 숫자 신뢰도나 점수로 판단을 꾸미지 않는다.
